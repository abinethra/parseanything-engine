\# ParseAnything Engine



High-Fidelity Universal Document Ingestion Engine built for high-stakes domains (Private Equity, Investment Banking, Legal Diligence).



\## Project Structure

\- `src/parseanything/`: Core Python package containing parser modules

\- `tests/`: Unit and integration test suite

\- `samples/`: Sample multi-format files for local testing

\- `outputs/`: Default folder for generated Markdown and JSON outputs

python -m venv venv

call venv\\Scripts\\activate
